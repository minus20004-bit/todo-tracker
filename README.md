# Консольный трекер задач (Task Tracker)

Практическая работа по курсу "Введение в специальность".

## 1. Постановка задачи
Проект решает проблему неэффективного планирования учебного времени среди студентов. 
Цель — разработать легкий консольный инструмент для фиксации текущих задач и отслеживания прогресса.

## 2. Инструменты проектирования и разработки
- **Тип ПО:** Console Application (Консольное приложение)
- **Язык программирования:** Python 3 (архитектура с персистентным хранением в JSON)
- **Система контроля версий:** Git + GitHub

## 3. Инструкция по запуску
1. Установите Python версии 3.x с официального сайта.
2. Скачайте проект или клонируйте репозиторий:
   `git clone https://github.com/minus20004-bit/todo-tracker`
3. Перейдите в папку с проектом: `cd todo-tracker`
4. Запустите приложение: `python main.py`

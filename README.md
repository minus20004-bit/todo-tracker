# Консольный трекер задач (Task Tracker)

Практическая работа по курсу "Введение в специальность".

## Постановка задачи
Проект решает проблему неэффективного тайм-менеджмента и прокрастинации среди студентов. 
Цель — создать легковесный консольный инструмент для быстрой фиксации текущих задач и отслеживания их выполнения.

## Инструменты
- **Тип ПО:** Console Application (Консольное приложение)
- **Язык:** Python 3
- **Контроль версий:** Git + GitHub

## Инструкция по запуску
1. Установите Python версии 3.x с официального сайта.
2. Скачайте проект или клонируйте репозиторий:
   `git clone https://github.com/minus20004-bit/todo-tracker`
3. Перейдите в папку с проектом: `cd todo-tracker`
4. Запустите приложение: `python main.py`
